# Bookflix

## Open in VS Code

Open this folder in VS Code, then open `index.html` in a browser. For automatic reload while editing, use the VS Code Live Server extension.

## Features

- Add books from the **＋ Add Book** button. Add a title, author, category, cover image URL, synopsis and optional story text.
- Search books, filter by category, open book details, and save books to My List.
- The three-line button on the right opens the main navigation menu.
- No Guest or Login control is shown on the homepage.
- Books added and My List entries are saved in this browser's local storage. They do not sync between devices.

The sample covers use online images. Use an image URL for a cover, or leave it blank to show a generated text cover.
